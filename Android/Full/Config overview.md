# Config overview - Android - Full

This package contains every Android resource for every tier and licence, including resources without tier and licence markers, plus the Conditional Access policies that apply to Android with their groups, named locations, and migration table.

> [!WARNING]
> Do not combine this package with a BP or E5 package for Android. Microsoft Intune imports can create duplicate policies rather than reconcile packages.

Review tenant-specific values, licences, dependencies, and assignments before import. Do not bulk import assignments. Import to a pilot group and validate the outcome before wider deployment.
