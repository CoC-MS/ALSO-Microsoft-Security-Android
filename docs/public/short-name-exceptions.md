# 🏷️ Short-name exceptions

[Public documentation](README.md) | [Policy naming](policy-naming.md)

Not every exported Android resource uses the complete naming convention. In this repository, compliance policies and assignment filters include shorter `ALSO`-prefixed names, and some app resources use descriptive names without licence or tier markers.

Do not infer a missing licence, tier, platform, or assignment scope from a short name. Review the resource's settings, description, dependencies, and licensing before deployment. The exports have not been renamed or normalized.

## Existing spelling and separators

The checked-in Settings Catalog filenames include the source spelling `Android Enterprice` and use both hyphen and typographic-dash separators. These are existing export filenames, not naming guidance for new policies.

See [Policy naming](policy-naming.md) for the common format and [File structure](file-structure.md) for the checked-in package contents.
